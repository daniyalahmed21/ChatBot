# AI Powered Web Apps

This repository contains two modern AI-powered projects: **AI ChatBot** and **Review Summarizer**, built with a clean, responsive UI and robust backend integration.

## 1. AI ChatBot

A modern, real-time chat application powered by **Google's Gemini AI**, with conversation history management and a smooth, user-friendly interface.

### Features

- 💬 Real-time AI chat interface
- 🔄 Conversation history persistence
- ⚡ Smooth typing animations
- 📱 Fully responsive design
- 🎨 Clean, modern UI with hidden scrollbars
- ⌨️ Keyboard shortcuts (Enter to send, Shift+Enter for new line)

### Tech Stack

**Frontend:**

- React with TypeScript
- React Hook Form for form management
- Axios for API calls
- React Markdown for message rendering
- Tailwind CSS for styling

**Backend:**

- Express.js
- Google Generative AI (Gemini)
- Zod for validation
- TypeScript

## 2. Review Summarizer

An AI-powered review summarization tool that extracts key insights from user reviews, simplifying analysis for businesses and product managers.

- 📊 Easy-to-read summaries

- React with TypeScript
- Axios for API calls
- Tailwind CSS for styling

**Backend:**
