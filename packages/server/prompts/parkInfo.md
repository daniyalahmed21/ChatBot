Whispering Pines Municipal Park: Visitor Guide
(A) Welcome & General Information
| Category | Detail |
| :--- | :--- |
| Location | 123 Forest Lane, Greenside, USA (Near the corner of Oak St. and River Rd.) |
| Operating Hours | Park Grounds: Sunrise to Sunset (Daily) |
| | Visitor Center: 9:00 AM – 5:00 PM (Tues - Sun, closed Mondays) |
| | Gate: Main vehicle gate locks promptly at sunset. All visitors must exit prior to this time. |
| Contact | General Inquiries: (555) 123-PINE (7463) |
| | Emergency (Park Rangers): (555) 911-PARK (7275) |
| Pets | Dogs are welcome but must be kept on a leash (max. 6 feet) at all times. Designated off-leash Dog Park is located near Parking Lot C. |
| Admission | Free (Parking is also free) |

(B) Park Amenities & Features
| Feature | Location / Description |
| :--- | :--- |
| Hiking Trails | 5 marked trails ranging from Easy (1-mile paved loop) to Difficult (4-mile steep ascent to "Eagle's Peak" overlook). Trail maps available at the Visitor Center. |
| Picnic Areas | Main Grove: 15 tables and 5 BBQ grills. Riverbank: 8 tables, no grills. Both operate on a first-come, first-served basis, unless a pavilion is reserved. |
| Pavilion Rental| One large pavilion ("The Hearth") is available for reservation via the park website. Max capacity 80 people. |
| Playgrounds | Pinecone Playground: For ages 2-5. Adventure Zone: For ages 6-12 (near Parking Lot B). |
| Visitor Center | Offers restrooms, gift shop, nature exhibits, and trail maps. |
| Restrooms | Available at the Visitor Center and near Parking Lot C. Portable toilets are seasonally available at the Eagle's Peak Trailhead. |
| Water Activities| Small, non-motorized boats (kayaks, canoes) are permitted on Mirror Lake. Swimming is strictly prohibited. |

(C) Rules & Safety
| Rule/Safety Concern | Detail |
| :--- | :--- |
| Leave No Trace | Pack out all trash. Do not feed wildlife. Stay on marked trails. |
| Fires | Only permitted in designated BBQ grills in the Main Grove. No ground fires or campfires are allowed anywhere in the park. |
| Wildlife | Black bears and coyotes are occasionally sighted. Secure food and make noise while hiking. Bear spray is legal but must be carried safely. |
| Drones | Drones are not permitted without a special park permit. |
| Emergencies | Dial the Ranger Emergency Line (555) 911-PARK for immediate assistance. Signal is generally good throughout the park. |
